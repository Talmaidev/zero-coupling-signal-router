## 四、必踩的坑（已验证，勿重蹈覆辙）

1. **WASAPI 链接错误（LNK2019）**：`IID_IMMDeviceEnumerator` 等4个符号未解析。mmdevapi.lib 不够，必须在代码中 `#include <initguid.h>` + 手动 `DEFINE_GUID(...)` 4个标准值。GUID值见 `modules/audiomix/audiomix.c`。

2. **`__linux__`/`__ANDROID__` 冲突**：Android NDK clang 同时定义两者。所有 `#if defined(__linux__)` 必须加 `__ANDROID__` 优先分支，否则引 X11/ALSA 头文件编译失败。

3. **根 CMake 不能复用给 Android**：`if(UNIX AND NOT APPLE)` 块会在 Android 上执行，`find_package(X11 REQUIRED)` 直接失败。Android 必须用独立 `build/android/CMakeLists.txt`。

4. **audiomix 线程模型与 AAudio 不兼容**：现有是拉模式（线程主动推），AAudio 是推模式（系统回调拉）。需要加 PCM 环形缓冲抽象层，不是"加个后端"那么简单。

5. **绝对禁止重写整个文件**：用 Edit 做精确字符串替换。曾误删 `zcsr_gl_set_target` 函数签名，用户非常不满。改完用 grep 确认所有公共API存在。

6. **MSVC 警告**：C4267（size_t→GLsizei）必须显式 cast；C4309（`(SHORT)0x8000`）直接用 `0x8000`。用户要求 Release 零警告。
